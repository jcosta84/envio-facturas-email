# Envio de Facturas EDEC — Python + CustomTkinter

## Preparação
1. Execute `sql/schema_completo.sql` no MySQL Workbench.
2. Edite `config.ini` com as credenciais corretas.
3. Instale as dependências: `py -m pip install -r requirements.txt`.
4. Inicie: `py main.py`.

Utilizador inicial: `admin` — palavra-passe: `admin123`. Altere-a antes de utilizar em produção.

## Gerar executável
No PowerShell: `Set-ExecutionPolicy -Scope Process Bypass` e depois `.\gerar_executavel.ps1`.
